## 11. 버전 관리 (GitHub)

### 레포지토리
| 항목 | 내용 |
|------|------|
| 레포 이름 | endtoend-todolist |
| 구조 | 모노레포 (frontend / backend / terraform 단일 레포) |
| 가시성 | Public |

---

### 브랜치 전략
| 브랜치 | 용도 |
|--------|------|
| main | 배포 기준 브랜치 — CI/CD 트리거 |

**흐름**
기능 개발 → main 바로 push → 자동 배포

---

### CI/CD 연계
| 변경 경로 | 트리거 | 배포 대상 |
|-----------|--------|-----------|
| frontend/** | main push | AWS Amplify |
| backend/** | main push | AWS Elastic Beanstalk |
| terraform/** | main push | 수동 실행 (terraform apply) |

> terraform은 인프라 변경 특성상 자동 배포 제외 — 반드시 내용 확인 후 수동 apply
