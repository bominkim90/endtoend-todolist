Service: TodoList — a personal productivity web app.
Target user: Individual professionals.

Screen: Main todo list page (web, desktop-first, after login)
Goal: Display the user's todo items and allow quick actions.

Layout requirements:
- Top navigation bar: app name left, user avatar/logout right
- Page title: "My Todos"
- "+ New Todo" button (prominent, top right of list area)
- Todo item card list (vertical scroll):
  Each card contains:
  - Checkbox (complete/incomplete toggle) on the left
  - Todo title (bold if incomplete, strikethrough if completed)
  - Created date (small, gray)
  - Delete icon on the right
- Empty state: friendly message when no todos exist
- Clean, minimal, light theme
