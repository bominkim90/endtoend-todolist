Service: TodoList — a personal productivity web app.
Target user: Individual professionals.

Screen: Todo create/edit page (web, desktop-first)
Goal: Let users write a todo with a title and rich text content.

Layout requirements:
- Top navigation: back arrow left, "Save" button right
- Large title input field at the top (placeholder: "Todo title")
- Below title: rich text editor area (TipTap style)
  - Editor toolbar: Bold, Italic, Bullet list, Image upload icon
  - Large open writing area below toolbar
- Clean document-like layout (white background, generous padding)
- Minimal, distraction-free writing experience
