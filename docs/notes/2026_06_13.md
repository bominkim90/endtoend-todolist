### 피그마 -> 커서 mcp 연결 흐름
`
커서(프롬프트) → 피그마 MCP 서버(중간 번역) → 피그마 API(디자인 JSON 반환) → 커서 AI(JSON 해석 → Next.js 코드 생성)
`
---

### 피그마 MCP 서버가 내 로컬에서 도는 이유

- **상황**: 커서에서 피그마 MCP 연결하려고 했는데, 
  서버가 내 로컬 PC에서 실행된다는 게 이해 안 됐음

- **이유**: 
  피그마는 그냥 REST API만 열어둔 거야. 
  "우리 파일 데이터 가져가고 싶으면 이 API 써" 하고.
  figma-developer-mcp는 피그마가 만든 게 아니라 
  써드파티 오픈소스야. 피그마 REST API를 MCP 프로토콜로 
  감싼 번역기인데, 이게 내 로컬에서 실행되는 거.

- **흐름**: 
  커서 → 내 로컬 MCP 서버(3333포트) (피그마 MCP서버를 터미널에서 실행중)
       → 피그마 REST API(피그마 클라우드) 
       → JSON 데이터 반환 
       → 커서가 코드 생성

- **기억할 것**: 
  피그마 공식 MCP(유료)는 로컬 서버 안 켜도 됨.
  지금 방식(figma-developer-mcp)은 무료 우회 방법이라 
  매번 터미널에서 서버 직접 켜야 함.
  실무에서 피그마 Pro 쓰면 URL만 등록하면 끝.
