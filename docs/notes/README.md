# 📝 오답노트

> 에러를 만났을 때, 또는 "아 이런 흐름이구나" 하고 이해된 순간에만 기록.
> 길게 쓰지 말고, 딱 4줄만.

---

## 템플릿

```
### [제목 — 한 줄로, 뭘 겪었는지]

- **상황**: 어떤 기능을 만들다가 무슨 일이 생겼는지
- **이유**: 왜 그 에러가 났는지, 또는 왜 그렇게 동작하는지
- **흐름**: 관련된 레이어 흐름 한 줄 (프론트 → 백엔드 → DB 중 해당되는 것)
- **기억할 것**: 다음에 이 상황 만나면 바로 떠올릴 핵심 한 줄
```

---

## 예시

### JWT 만료됐을 때 401 에러가 계속 남

- **상황**: 로그인 후 한참 있다가 API 호출하면 계속 401 에러
- **이유**: 프론트가 만료된 Access Token을 계속 보내고 있었음. 백엔드는 만료된 토큰을 당연히 거부
- **흐름**: 프론트 요청 → 백엔드 JWT 필터 → 만료 감지 → 401 반환 → 프론트가 갱신 없이 재요청
- **기억할 것**: Access Token은 짧게 유지, 만료되면 Refresh Token으로 재발급하는 구조 필요
